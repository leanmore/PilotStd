# Known Security Issues

## SEC-001: Systemic @require_role Decorator Order Bug (Auth Bypass)

**Severity**: High
**Discovered**: 2026-08-15
**Root Cause**: `@require_role("admin")` applied *outside* `@router.get/post` → FastAPI registers the unwrapped function → admin auth enforcement never executed.

**Correct Fix Pattern** (see `docker/api/logs.py` as reference):
1. Place `@require_role` *inside* (below) the route decorator
2. Ensure handler signature includes `request: Request`
3. Add auth enforcement tests
