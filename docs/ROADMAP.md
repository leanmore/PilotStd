## 〇、规则（先读，防"死日期"）

1. **日期是承诺，不是愿望**：到期未开工 → 该事项退回 §三「未排期」，并在 §五 写明原因。禁止挂着假日期。
2. **裁决随对话进行**：不排"决策会"。事项开工前，我把待裁决项整理成"选项 + 建议"，你回一句话即可；未裁决则不开工。
3. **每项完成的判据**：CI 全绿 + 验收项逐条勾选 + 对应文档同批更新（R-006）。缺一条不算完成。
4. **代码能不动就不动**：除本文件列出的工程外，不做结构调整。
