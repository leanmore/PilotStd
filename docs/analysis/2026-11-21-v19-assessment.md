# V-19 评估：`no-literal` 口径收紧的影响面（2026-11-21，只读）

> 目的：回答“把 G-055 的 `no-literal` 排除项收紧为可映射，会产生多少阻断/噪音、是否值得做、怎么分批”。
> 本文只做评估，**未改门禁、未改基线、未收紧口径**。数据取自 `scripts/design_token_baseline.json`（基线 17 组）
> 与 `web/src/` 全量静态扫描。

## 一、`no-literal` 177 条的真实构成

9 个不同取值，可分两类：

| 取值 | 条数 | 分类 |
|---|---:|---|
| `0` | 67 | 非视觉值 |
| `none` | 44 | 非视觉值 |
| `100%` | 33 | **布局单位** |
| `auto` | 16 | 非视觉值 |
| `transparent` | 7 | 非视觉值 |
| `100vh` | 4 | **布局单位** |
| `1fr` | 3 | **布局单位** |
| `fit-content` | 2 | **布局单位** |
| `unset` | 1 | 非视觉值 |

- **非视觉值 134 条**（`0/none/auto/transparent/unset`）：不是“硬编码视觉样式”，收紧只会制造噪音。
- **布局单位 42 条**（`100%/100vh/1fr/fit-content`）：语义上是布局尺寸，存在“是否应令牌化”的讨论空间。

## 二、收紧的量化影响

| 方案 | 收紧对象 | 新增阻断 | 结论 |
|---|---|---:|---|
| 方案 A | 仅布局单位（`%` + `vh` + `fr` + `fit-content`） | **+42** | 可做，但需一次性重生成基线 + 人工评审 42 条 |
| 方案 B | 布局单位 + `transparent/none/auto` | +91 | 噪音量级过大，不建议 |
| 方案 C | 维持现状 | 0 | 当前策略 |

**建议（已按裁决执行方向）**：分批做方案 A —— 第一批 `100%` 33 条，第二批 `vh/fr/fit-content` 9 条；134 条非视觉值不纳入。

## 三、overlay 半透明底：196 处 / 20 个 alpha 取值

Top 取值（按出现次数）：`0.08`(24)、`0.12`(20)、`0.15`(17)、`0.3`(15)、`0.85`(14)、`0.05`(12)、
`0.1`(11)、`0.25`(11)、`0.06`(10)、`0.2`(10)，其余 10 个取值各 1~8 处。

- 分布**高度分散**，但集中在 4 档附近（≈0.06 / 0.12 / 0.30 / 0.85）。
- 统一为 4 档标度（`--overlay-weak/soft/strong/solid`）会产生**可见视觉变化**，不属本轮债务。
- 处置：**维持现状**，4 档标度登记为观察项 V-20（`04-watch`），需产品确认视觉变化后才做，不阻塞 P5。

## 四、box-shadow：47 处声明 / 20 个不同值

- 33 处已使用令牌（`--shadow-xs` 10、`--shadow-sm` 8、`--focus-ring` 5、`--shadow-md` 4、
  `--button-primary-shadow` 3、`--shadow-lg` 3）。
- 仅 **14 处为原生值**，且彼此差异明显（一次性组合居多）。
- 结论：**不再新拆 `--shadow-sm/md/lg` 层级**（会造“看似令牌实则一次性”的假令牌）；把 14 条原生值映射到既有层级；
  无法匹配的只加 TODO、登记 A-52。

## 五、结论与执行顺序

1. `no-literal` 收紧**分批**（先 `100%` 33 条，再 `vh/fr/fit-content` 9 条），每批独立 PR + 一次人工评审 + 三处数字同步。
2. overlay **维持现状**，4 档标度进 `04-watch` V-20。
3. 阴影**只映射不新拆**，14 条原生值 → 既有 `--shadow-*`；不匹配者加 TODO。
4. 134 条非视觉值**不纳入**收紧，维持观察。
