版本 0.2.0 | 2026-06-09

---

## 一、软件简介

PilotStd 是一款面向标准化工作者和企业档案管理人员的标准文件管理工具，支持：

- **自动识别**文件名中的标准号（GB、GB/T、GB/Z、SH/T 等 76 类行业标准）
- **批量查询**标准有效性（现行 / 废止 / 即将实施）
- **下载**、**归类**、**整理**标准文件
- **过期监控**与**更新提醒**

数据来源：全国标准信息公共服务平台、工标网、南京标准网。

## 二、快速上手

### 2.1 启动软件

双击 `main.py` 或在命令行运行：

```bash
python main.py
```

首次启动显示欢迎页，可勾选"不再显示"跳过。

### 2.2 操作流程

```
左侧文件树选文件夹 → 📂选择 → 🔎扫描 → 🔍查询 → 📝规范化命名 → 💾归档
```

查询完成后，软件自动按匹配度分类：
- **完全匹配（exact）** → 现行标准→规范化归档；废止标准→移入过期作废
- **非完全匹配（older/newer/code_only/mismatch）** → 归入"待确认"，等以后重查

也可直接点击 **▶ 自动运行** 一键完成全部步骤。

### 2.3 工具栏按钮说明

| 按钮 | 功能 | 说明 |
|---|---|---|
| 📂 **选择** | 导入文件夹 | 将文件夹导入项目，在左侧文件树中定位 |
| 🔎 **扫描** | 文件扫描 | 扫描目录中的 PDF/DOC/DOCX/TXT 文件，解析标准号 |
| 🔍 **查询** | 有效性查询 | 将扫描结果提交到查询网站，获取标准状态 |
| ⬇ **下载** | 下载文件 | 对有更新版本的标准执行下载。队列为空时可**从文件导入下载**（文件菜单） |
| 📝 **规范化命名** | 重命名 | 按标准规范重命名文件 |
| 💾 **归档** | 文件移动 | 将标准文件移入分类目录 |
| ▶ **一键处理** | 一键全流程 | 依次执行 扫描→查询→下载→规范化命名→归档 |
| 📢 **公告检查** | 公告更新 | 抓取国家标准/行业标准/地方标准公告，检测本地文件变更 |

## 四、查询策略说明

### 4.1 搜索原理

软件采用**渐进式搜索策略**，对每条标准从窄到宽尝试搜索词：

| 优先级 | 搜索词示例 | 说明 |
|---|---|---|
| 1 | `GB/T 19001 2016` | 代号+序号+年份，最精确 |
| 2 | `GB/T 19001` | 去掉年份 |
| 3 | `GB/T 19001 2016` | 代号+序号+年份（去部分号） |
| 4 | `19001` | 纯序号兜底 |
| 5 | `GB/T 19001 2016 质量管理` | 加名称关键词，最后手段 |

搜索过程中，一旦匹配到代号+序号一致的结果（得分 ≥50），立即终止不再尝试更宽泛的搜索词，以减少无效请求。

### 4.2 匹配度打分

| 得分 | 含义 | 后续处理 |
|------|------|----------|
| **100 (exact)** | 代号、序号、部分号、年份全部一致 | 现行→规范化归档；废止→移入过期作废 |
| **80 (newer)** | 代号+序号一致，网站年份更新 | 归入"待确认" |
| **50 (older)** | 代号+序号一致，网站年份更旧 | 归入"待确认" |
| **20 (code_only)** | 仅代号匹配 | 归入"待确认" |
| **0 (mismatch)** | 无意义匹配 | 归入"待确认" |

**只有 exact（100分）的结果才写入缓存并进入后续流程。非 exact 统一归入"待确认"，不参与分类处理，等以后重查。**

### 4.3 查询网站优先级

**国家标准 (GB/GB/T)**：南京标准网 → 全国标准平台 → 工标网
**行业标准 (SH/NB/HG/JB等)**：HBBA 行业标准平台 → 南京标准网 → 工标网
**国际标准 (ISO/IEC)**：ISO 标准平台 → 南京标准网

用户可在设置中自定义偏好顺序（置顶叠加，不覆盖默认路由）。

## 五、搜索技巧

参考工标网官方指南：

1. **多个关键词**用空格分隔，搜索更精确。例如搜索 `玩具 规范` 比只搜 `玩具` 效果好
2. **避免错别字**。输入"塑料购物带"可能找不到"塑料购物袋"
3. **标准编号格式正确**。`GB/T 19001-2016` 不能写成 `GB/T190012016`（缺少空格和连接符）
4. **确认搜索对象是标准**。部分文件可能不是标准，或该标准尚未在国家系统中收录
5. **年代久远的标准**可能在部分网站中查不到，可尝试其他查询源
6. **工标网访问限制**：未注册用户最多访问 **200 个页面**，超限后将无法继续查询。软件已内置冷却机制（每 180 次请求自动暂停 10 分钟）以延缓触发。如需高频使用，建议注册工标网会员。备用 IP `http://222.73.18.35` 在主站不可用时自动切换。

## 六、文件管理

### 6.1 目录结构

软件按以下结构自动归类标准文件：

```
{D:\标准}                          ← 用户配置的根目录
├── GB 国家标准/
│   ├── GBT 19001—2016 质量管理体系.pdf
│   ├── GBZ 1—2020 指导文件.pdf
│   └── 过期作废/                   ← 过期标准自动移入此处
│       └── GB 1234—1986 旧标准.pdf
├── SH 石油化工/
│   └── SHT 1610—2010 石油化工规范.pdf
└── ...
```

### 6.2 文件命名规范

下载后的文件按以下格式自动命名：

```
{文件代号（去除/）} {顺序号}[.{部分号}]—{年份} {标准名称}.pdf
```

例如：`GBT 19001—2016 质量管理体系.pdf`

## 九、命令行模式

```bash
# 扫描目录（支持多目录）
python -m pilotstd.cli.commands scan D:\标准 D:\标准2 --format json

# 查询标准有效性
python -m pilotstd.cli.commands query --file standards.txt

# 下载：从查询队列下载（需先执行 query）
python -m pilotstd.cli.commands download

# 下载：从文件直接导入标准号下载（绕开查询）
python -m pilotstd.cli.commands download -f list.txt

# 一键处理：扫描→查询→下载→归档
python -m pilotstd.cli.commands auto D:\标准

# 其他命令
python -m pilotstd.cli.commands normalize "file.pdf"
python -m pilotstd.cli.commands move "file.pdf" --root "D:\标准"
python -m pilotstd.cli.commands expire "old.pdf"
python -m pilotstd.cli.commands announce
python -m pilotstd.cli.commands task
```

## 十、常见问题

**Q: 查询结果为空？**
A: 检查网络连接。年代久远的标准可能未收录。待确认清单中的项目需人工核实。

**Q: 为什么有些标准跳过下载直接归档了？**
A: 查询结果完全匹配（exact=100）且现行有效的标准，本地已有文件，无需重复下载，直接规范化后归档。

**Q: 什么是"待确认"？**
A: 非精确匹配（exact）的结果，说明网站返回与本地解析不完全一致（如年份不同、仅代号匹配等）。只有置信100分的精确匹配才进入后续流程，非精确项保留在待确认列表，等以后重查时可能获得精确匹配。

**Q: 下载失败？**
A: 确认该标准非采标（ISO/IEC 等同采用的标准受版权保护，无法直接下载）。检查网络和验证码识别。

**Q: 工标网访问受限？**
A: 未注册用户只能访问 200 个页面。可尝试使用备用 IP `http://222.73.18.35`，或注册会员。

**Q: 文件扫描无法识别？**
A: 检查文件名是否包含标准号格式（如 `GB/T 19001-2020`）。支持 `.pdf` `.doc` `.docx` `.txt` 格式。
