# 人工测试方案

**版本：** v3.1
**日期：** 2026-06-09
**测试对象：** PyInstaller 打包后的 exe 文件
**测试环境：** 另一台机器 YangPC，Windows 11，删旧 config/data/logs，裸启
**测试方式：** 人工操作 GUI，真实网络
**源目录：** `D:\标准`
**输出目录：** `E:\标准`

> 本方案用于打包后的人工验收测试。源码环境全自动测试见 `本机源码全量压力测试方案.md`。

---

## 一、测试前准备

### 1.1 环境清理

```
- 删除 data/ 目录（清除缓存，确保查询走真实网络）
- 删除 logs/ 目录（清除历史日志，便于观察本轮日志）
- 确认 config/ 目录存在且可写
- 确认 pilotstd_env/ 虚拟环境可用
```

### 1.2 源/目标目录

| 目录 | 路径 | 说明 |
|------|------|------|
| 源目录 | `D:\标准` | 含各类标准文件（PDF + Word + 子目录 + 过期作废/） |
| 输出目录 | `E:\标准` | 归档整理输出 |

### 1.3 启动命令

```bash
cd d:\PilotStd
python main.py
```

### 1.4 OCR 配置（百度云）

公告 OCR 功能需在 `data/config.json` 中配置百度云 API 密钥：

```json
"ocr": {
  "provider": "baidu",
  "api_key": "wOM9MziWlmtxWDrvaHwxdvMZ",
  "secret_key": "Uy1crHpWlZV1qxrow7HTYXJHGVOmzE6k"
}
```

> 此配置已从仓库 `data/config.json` 移除，测试时需手动添加到配置文件中。
