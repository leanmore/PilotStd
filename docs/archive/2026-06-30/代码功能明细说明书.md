- **v0.1.5 新增**：地方标准 DB\d{2,4}(/T)? 正则 + `_exact_match_db()`；`_detect_language` 识别中文版/英文版；版次跳过（10版/Tenth Edition）；`_trim_prefix` 逐词验证 code_mapping；数字后缀字母（API 6D）；`_extract_number` 返回 (int, suffix)

### 4.2 SearchStrategy（search_strategy.py，237行）

- 代号变体检测（GB ↔ GB/T）
- STATUS_MAP 状态归一化（含英文→中文映射）

### 4.3 查询适配器（6个）

| HbbaAdapter | hbba.sacinfo.org.cn | POST JSON | ✅(v1.2) | ✅(v1.2) | /stdDetail/{pk}→"代替标准" |
| IsoGovAdapter | std.samr.gov.cn（国际标准） | GET gjPage | ✅(v1.2) | ❌ | 网站不提供 |

## 九、门面层（pilotstd/manager.py，510行）

StandardManager 统一 API：
- `scan_directory(path)` → 扫描+解析
- `query(parsed_list, progress_callback)` → 批量查询 + `_classify_after_query()` 自动分类路由
- `download()` → 纯执行（从 `_download_list` 取），过期处理（`_expire_list`）
- `organize(parsed_list)` → 归类归档（PDF走safe_move，Word镜像源目录结构）
- `organize_skipped_dirs` → 跳过目录归档（目标存在时逐文件比对，移动前清只读）
- `organize_fallback(source_root)` → 兜底镜像（残余文件按源目录结构搬走，过滤系统垃圾）
- `handle_expired` / `auto_run(path)` → 一键全流程
- `_resolve_replaces(std_number)` → 跨站补查替代关系

分类路由（`_classify_after_query`）：
- **规则0**：match_status 非 exact → pending（只缓存精确匹配，非精确等重查）
- 未查到/未知/待确认 → pending
- 废止+newer+GB → download（远程版即替代）；废止+!newer → expire
- 现行+newer+GB → download；现行+!newer → 跳过
- 非 GB 类 → 跳过下载
- 分类结果存入 `_download_list` / `_expire_list` / `_pending_list`

## 十四、关键架构决策

1. **渐进式搜索**：query_with_strategy 生成 5 级搜索词 → 多候选取最优 → match_result 打分
2. **待确认机制**：非 exact（分数 < 100）→ status="待确认" → next_action="pending" → 等重查。只有 exact 进入后续流程。
3. **分类路由**（v1.2）：查询后自动按 status + match_status + GB 类型分类，废止标准不盲目下载，match_status=="newer" 才入下载队列
4. **下载安全**：待确认项排除下载、采标标准跳过、配额耗尽明确提示
5. **Word 文件处理**：扫描标记 word_template → 跳过查询/下载 → 归档时镜像
6. **排除目录**：跳过扫描 → 原封不动整体移动到输出根对应位置
7. **缓存双通道**：网络缓存（30/7天TTL）优先，公告缓存（永久）回退
8. **站点轮转**：SiteRotator 管理冷却时间，防止 IP 被封
9. **schema 迁移**：7 级增量迁移，向下兼容旧库
10. **Docker Web**：FastAPI + Vue 3 SPA，多用户 JWT 认证，响应式三档适配
11. **num_prefix 透传**：Parser→query→download 完整链路传递字母前缀（ASME B16.5 的 B）
12. **part_match 守卫**：match_result 中部分号不匹配直接判 mismatch，防止 GB 30000.3 vs GB 30000.30 误判
