# 非技术决策者规则速查表 (Rule Quick Reference)

> **适用范围**：非技术背景决策者（产品/业务负责人）在收到 Claude Code `[决策请求]` 或参谋 `[决策辅助]` 时，快速理解规则含义并做出判断。
> **核心原则**：所有规则翻译为业务语言；不包含代码片段；不要求理解技术实现细节。
> **维护责任**：由 Qwen/DeepSeek 共同维护，新增/修订规则后 24 小时内同步更新本表。

---

## 使用说明

- **按规则编号排序**：G-XXX（门禁规则）在前，ADR-XXX（架构决策记录）在后。
- **每条规则固定 5 字段**：当遇到情况 / 规则要求 / 业务原因 / 通常选择 / 例外情况。
- **禁止模糊表述**："通常选择"必须给出明确动作，"例外情况"必须给出可验证的触发条件。
- **与决策辅助协议联动**：参谋在 `[决策辅助]` 中引用规则时，必须附带本表中对应条目的链接或原文摘要。

## G-033 内存泄漏检查

**当遇到情况**：修改了日志组件、表格组件、图表组件，或任何涉及定时器、事件监听器、WebSocket 连接的代码。

**规则要求**：必须验证组件卸载时清理了所有定时器、监听器和连接。

**业务原因是**：不清理会导致用户长时间使用后页面卡顿甚至崩溃，直接影响用户体验和产品口碑；移动端尤其敏感。

**通常选择**：在组件销毁生命周期中显式清理所有资源。

**例外情况**：仅当组件在整个应用生命周期内只创建一次且永不销毁（如根布局、全局状态容器）时可豁免，但必须在代码注释中标注豁免理由及规则编号。

## G-041 用户敏感数据脱敏

**当遇到情况**：任何涉及用户姓名、手机号、身份证、银行卡、地址等个人信息的展示、导出、日志记录场景。

**规则要求**：数据在离开后端服务前必须完成脱敏，前端永远不接收明文敏感数据。

**业务原因是**：违反《个人信息保护法》及平台合规要求，可能导致法律风险、监管处罚及用户信任崩塌。

**通常选择**：使用统一脱敏工具函数处理，手机号保留前 3 后 4，姓名保留姓，身份证保留前 1 后 1。

**例外情况**：仅在用户本人主动发起"查看完整信息"操作且通过二次身份验证后，可临时返回明文，且必须记录审计日志。

## G-058 数据库变更必须可回滚

**当遇到情况**：执行任何数据库表结构修改、索引增删、数据迁移脚本。

**规则要求**：每个正向迁移脚本必须有对应的、经过验证的回滚脚本，且两者在同一提交中。

**业务原因是**：线上数据结构变更失败若无回滚方案，将导致服务长时间不可用，恢复时间从分钟级延长至小时级甚至天级。

**通常选择**：编写 `*.rollback.ts/sql` 文件，并在 CI 中自动验证回滚脚本可成功执行。

**例外情况**：纯追加型变更（如新增只读字段、新增独立表）且经 DBA 书面确认为"无损变更"时，可省略回滚脚本，但需在迁移文件头部标注 DBA 确认单号。

## ADR-007 第三方服务调用必须设超时与熔断

**当遇到情况**：集成新的外部 API、支付渠道、短信服务、地图服务等。

**规则要求**：所有外部调用必须配置明确的超时时间（≤5 秒）和熔断阈值（连续失败 ≥3 次触发）。

**业务原因是**：第三方服务不可控，无防护的调用会将外部故障传导至自身系统，导致雪崩式服务中断。

**通常选择**：使用统一 HTTP 客户端封装，默认超时 3 秒，熔断恢复窗口 30 秒。

**例外情况**：仅当第三方服务 SLA ≥ 99.99% 且调用为异步非阻塞（如后台数据同步）时，可将超时放宽至 10 秒、熔断阈值调至 5 次，但需在 ADR 中记录风险评估。

## ADR-012 配置项禁止硬编码

**当遇到情况**：需要设置 API 地址、密钥、功能开关、限流阈值等可变参数。

**规则要求**：所有配置项必须通过环境变量或配置中心注入，禁止写死在代码中。

**业务原因是**：硬编码导致每次调整都需重新发版，无法快速响应线上问题，且密钥泄露风险极高。

**通常选择**：使用 `.env` + 配置中心双轨制，本地开发用 `.env`，生产环境用配置中心。

**例外情况**：仅当配置值为行业固定标准且永不变动（如 HTTP 状态码 200/404、UTF-8 编码标识）时可硬编码，但需在代码注释中说明"此为行业标准常量，非业务配置"。

## 附录：规则速查索引

| 规则编号 | 关键词 | 业务影响等级 |
| :--- | :--- | :--- |
| G-033 | 内存泄漏、定时器、监听器 | 高（用户体验） |
| G-041 | 敏感数据、脱敏、隐私 | 极高（合规） |
| G-058 | 数据库变更、回滚、迁移 | 极高（可用性） |
| ADR-007 | 第三方服务、超时、熔断 | 高（稳定性） |
| ADR-012 | 配置项、硬编码、环境变量 | 中（运维效率） |

> **注**：业务影响等级定义：
> - **极高**：违反即可能导致法律风险、资金损失或核心服务完全中断
> - **高**：违反即可能导致显著用户体验下降或部分功能不可用
> - **中**：违反即导致运维效率降低或潜在风险累积
> - **低**：违反即导致代码质量下降但不直接影响业务（此类规则不纳入本速查表）
