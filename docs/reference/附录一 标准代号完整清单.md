## 说明

- **中国行业标准**：推荐性标准在代号后加 `/T`（如 `SH/T`），文件名中去除斜杠（如 `SHT`）
- **国际/国外标准**：通常以代号 + 空格 + 顺序号 + `:` + 年份表示（如 `ISO 9001:2015`）
- 软件内置此清单，启动时可在线检查更新
- 用户可在设置中手动添加或修改代号及对应名称

## 五、国外标准命名规范

> 本章定义 PilotStd 解析及搜索国外标准文件名的格式规则。
> **核心原则**：解析格式必须与各查询网站的搜索格式对齐，避免无意义的格式转换。

### 5.1 标准体系层级

```
ISO / IEC          ← 国际标准
  └─ CEN (EN)      ← 欧洲统一标准
       └─ BS / DIN / NF / UNE / NEN / ...  ← 成员国国家标准
```

- **采纳关系**：成员国采纳 EN 后冠以本国前缀，如 `BS EN 1092`、`DIN EN 1092`
- **等同采用 ISO**：`BS EN ISO 16852`（英国采纳欧标，欧标等同采用 ISO）
- **仅采用 ISO**：`BS ISO 9001`（英国直接采纳 ISO，不经 EN）

### 5.2 各机构命名格式

#### ISO — 国际标准化组织

```
格式: ISO [部分号] 顺序号[:或-]年份
示例: ISO 9001:2015, ISO 2037-1992, ISO/IEC 27001:2022
```

| 要素 | 规则 |
|------|------|
| 代号 | `ISO` 或 `ISO/IEC`（联合发布） |
| 编号 | 1-6 位纯数字 |
| 分隔符 | `:`（官方）或 `-`（文件名常见） |

#### IEC — 国际电工委员会

```
格式: IEC [部分号] 顺序号[:或-]年份
示例: IEC 61000-4-2:2008
```

多级部分号（如 `4-2`），当前取 `-` 前的数字作为 part。

#### EN — 欧洲标准

```
格式: [国家前缀 ]EN [部分号] 顺序号[:年份]
示例: BS EN 1092-1-2018, DIN EN 1092-1
```

国家前缀→全称映射：BS(英国)、DIN(德国)、NF(法国)、UNI(意大利)、UNE(西班牙)、NEN(荷兰)、SFS(芬兰)、SS(瑞典)、NS(挪威)、ÖNORM(奥地利)。

多段前缀 `BS EN`、`BS EN ISO` 保留不拆分。`-1` 后缀为部分号，不是年份。

#### ASME — 美国机械工程师协会

```
格式: ASME [分类前缀] 序号[.部分号][-年份]
分类前缀:
  B   — 管道/法兰/管件        B16.5, B31.1
  BPVC — 锅炉压力容器规范      BPVC-III, BPVC-VIII（分段用罗马数字）
  Y   — 工程制图              Y14.5
  PTC — 性能试验规程           PTC 6
  NQA — 核质量保证

示例: ASME B16.5-2020, ASME B31.1, ASME BPVC-III-2021
```

**BPVC 罗马数字**：njbz365 使用罗马数字搜索，"ASME BPVC-III" 命中，"ASME BPVC-3" 不命中。不得进行罗马→阿拉伯转换。BPVC 共 20 卷（I~XII），卷号+子分册+年份结构（如 `ASME BPVC-III-NCA-INT-VOL 12-1983`），当前 `match_result` 无法正常匹配，留为已知局限。

#### ANSI — 美国国家标准学会

```
格式: ANSI[/联合署名] [分类字母]序号[.部分号][补充件][-年份] [(R 复审年份)]
示例: ANSI/UL 560-1980, ANSI Z21.17a-1981（补充件后缀'a', 罕见）
```

复审标识 `(R 年份)` 表示复审确认继续有效，非发布年份，当前无法解析。

#### API — 美国石油学会

```
格式: API [类型] [数字代码][-年份]
类型: Spec(规范), Std(标准), RP(推荐作法), MPMS(石油计量手册), TR(技术报告)

示例: API RP 500-2023, API Spec 6A
```

数字分段：1-4=通用, 5=管材, 6=井口设备, 7=钻井, 8=健康安全。

#### ASTM — 美国材料试验协会

```
格式: ASTM [分类字母]序号[-年份]
分类字母: A(钢铁), B(有色金属), C(陶瓷/混凝土), D(杂项), E(杂项), F(终端产品), G(腐蚀/老化)

示例: ASTM D4236-94, ASTM A53/A53M-2020（双编号取首个）
```

### 5.3 文件名分隔符归一化

| 原始 | → | 处理 |
|------|---|------|
| `_` (下划线) | → | 空格 |
| `:` (冒号) | → | `-` |
| `+` | → | 空格 |
| `No.` | → | 删除 |
| `～~` (范围) | → | 删除后半 |
| `[]（）()【】` | → | 删除 |

### 5.4 年份识别规则

| 格式 | 示例 | 处理 |
|------|------|------|
| 4位年份 | `2020` | 直接使用 |
| 2位年份 | `94` | +1900 |
| 月份后缀 | `2018-12` | 取年份，丢弃月份 |
| 复审标识 | `(R 1983)` | 不视为发布年份 |
| 无年份 | `ASME B16.5` | year=0 |
