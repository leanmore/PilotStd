# PilotStd 环境需求

**日期**: 2026-05-29 | **版本**: v1.0

PilotStd 支持三种使用方式，环境需求如下。

---

## 一、三环境对比

| | 开发 | 桌面使用 | Docker 部署 |
|------|:--:|:--:|:--:|
| **目标用户** | 开发者 | 标准工程师 | 家庭用户 / NAS 管理员 |
| **Python** | 3.14 | 不需要 | 不需要（容器内置） |
| **Node.js** | 18+ | 不需要 | 不需要 |
| **Docker** | 不需要 | 不需要 | DSM 7.2+ Container Manager (Engine 24.0.2) / 其他 Linux: Engine 20.10+ |
| **访问方式** | 源码运行 | exe 双击 | 浏览器打开 `http://<NAS-IP>:9028` |
| **数据库** | SQLite（内嵌） | SQLite（内嵌） | SQLite（容器内） |
| **磁盘** | 项目源码 ~500MB | 标准库目录（按需） | 标准库 + 配置文件 + 日志 |

---

## 二、开发环境

在 Windows 11 本机运行源码、修改代码、运行测试。

### 必需

| 组件 | 版本 | 安装方式 |
|------|------|------|
| Python | 3.14+ | `python.org` 下载安装 |
| Node.js | 18+ (推荐 20 LTS) | `nodejs.org` 下载安装 |
| Git | 任意 | `git-scm.com` |

### Python 依赖

```bash
cd d:\PilotStd
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
pip install -r requirements-dev.txt  # 含 pytest/ruff/playwright
```

### Node.js 依赖

```bash
cd d:\PilotStd\web
npm install
```

### 验证

```bash
python -m pytest tests/ -q      # 后端测试 194 项
cd web && npm run build          # 前端构建
```

### 推荐 IDE

VS Code + Python 扩展 + Vue Language Features (Volar)

## 三、桌面使用

用户通过 PyInstaller 打包的 `PilotStd.exe` 运行。

### 必需

| 组件 | 说明 |
|------|------|
| Windows 10/11 | 64 位 |
| 磁盘空间 | 标准库目录按需（建议 10GB+） |
| 网络 | 可访问 njbz365.cn / std.samr.gov.cn / hbba.sacinfo.org.cn 等站点 |

### 不需要

Python、Node.js、Docker、任何开发工具。`PilotStd.exe` 是绿色单文件，双击运行。

### 运行

```
PilotStd.exe
```

数据存储在同一目录的 `config/`、`data/`、`logs/`、`downloads/` 中。

## 四、Docker 部署

在群晖 NAS 或其他支持 Docker 的设备上运行。

### 必需

| 组件 | 版本 | 说明 |
|------|------|------|
| Docker Engine | 20.10+ | `docker info` 查看 |
| Docker Compose | V2（`docker compose`，无 `-`） | `docker compose version` |
| 群晖 DSM | 7.0+（如使用群晖） | Docker 套件已安装 |

### 磁盘

| 挂载点 | 用途 | 宿主机路径 | 建议空间 |
|------|------|------|:--:|
| `/app/data` | 配置 + SQLite 数据库 | `./data` | 100MB |
| `/app/logs` | 应用日志 | `./logs` | 500MB |
| `/app/downloads` | 下载临时文件 | `./downloads` | 2GB |
| `/standards` | 标准库输出 | 按需配置 | 10GB+ |
| `/media` | 扫描源目录 | 按需配置 | — |

### 端口

默认 9028，可通过 `docker-compose.yml` 中 `ports` 映射自定义。

### 网络

容器需访问：njbz365.cn、std.samr.gov.cn、hbba.sacinfo.org.cn、iso.gov、csres.com。

### 启动

```bash
# 环境变量配置（可选）
export STANDARD_ROOT=/volume1/standards
export SCAN_SOURCE=/volume1/media
export ADMIN_PASSWORD=your_password

cd d:\PilotStd
docker compose -f docker/docker-compose.yml up -d
```

访问 `http://<NAS-IP>:9028`。

### 停止/更新

```bash
docker compose -f docker/docker-compose.yml down
docker compose -f docker/docker-compose.yml build --no-cache
docker compose -f docker/docker-compose.yml up -d
```

## 五、环境变量（Docker）

| 变量 | 默认值 | 说明 |
|------|------|------|
| `PUID` | `1000` | NAS 文件所有者 UID (`id -u`) |
| `PGID` | `100` | NAS 文件所有者 GID (`id -g`) |
| `TZ` | `Asia/Shanghai` | 时区 |
| `ADMIN_PASSWORD` | `admin` | Web 登录密码 |
| `JWT_SECRET` | 内置默认值 | JWT 签名密钥，建议修改 |
| `STANDARD_ROOT` | `~/标准` | 标准库输出目录 |
| `SCAN_SOURCE` | `/media` | 扫描源目录 |
