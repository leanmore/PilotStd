## 二、缺口 6 闭合明细（钉钉卡片更新，**[全文]**）

**来源**：[《更新钉钉互动卡片》](https://open.dingtalk.com/document/robots/update-dingtalk-interactive-cards.md)（open.dingtalk.com，HTTP 200，正文已取到）

| 项 | 官方原文要点 |
|---|---|
| **方法与路径** | `PUT /v1.0/im/interactiveCards`，`Host: api.dingtalk.com`，Header `x-acs-dingtalk-access-token`（访问凭证，必填） |
| **卡片定位** | **`outTrackId`**："唯一标示卡片的外部编码"，**由开发者自己生成**并作为入参传给钉钉（钉钉仅在用到它的场景代记 TrackId） |
| **更新内容** | `cardData.cardParamMap`（普通文本参数）/ `cardData.cardMediaIdParamMap`（多媒体参数）；`privateData`（**按用户指定可见按钮列表**：key＝userId，value＝用户数据，含同名两参数） |
| **增量 vs 覆盖** | `cardOptions.updateCardDataByKey` / `updatePrivateDataByKey`：**不填默认覆盖更新**；置 `true` 则"按 key 更新" |
| **用户 ID 口径** | `userIdType`：`1`＝userid（默认）/ `2`＝unionId，影响 `receiverUserIdList` 与 `privateData` 的填法 |
| **权限** | **企业内部应用：支持**（需"会话管理权限"）；第三方企业应用：支持；**第三方个人应用：暂不支持** |
| **返回** | `{"success": "true"}` |
| **错误码（节选，均为文档原文）** | `invalidParameter.param.empty` / `paramBlank` / `sendCardMessageFailed` / `cidDecryptError` / `sceneGroupNotFound`（非场景群）/ `chatbotNotFound` / `uidDecryptError` / `duplicateKey`（模板占位符重复 Key）/ `getPictureFailed` / `contentCheckError` / `outTrackIdLengthLimited` / `systemBusy` |

**对 PilotStd 的直接含义（供阶段 3 定义用）**：
1. **"钉钉不可编辑"的旧结论不成立**——可编辑，但**前提是"卡片模板 + outTrackId"**（PilotStd 现有钉钉渠道走群机器人 webhook，**没有**模板与 TrackId 概念）；
2. ⇒ 阶段 3 若要启用钉钉"原地更新"，需先具备：①企业级形态（`_enterprise=True` 分支已有骨架）；②**卡片模板 id**；③**生成并持久化 `outTrackId`**（与消息 id 一起落库，复用既有的 `channel_message_ids` 列）；
3. **`outTrackIdLengthLimited`** 提示有长度上限 ⇒ 生成规则需保守（如 `plt-<message_id>`）。
