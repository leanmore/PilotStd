## 2. 本轮修复（均带回归用例）

### 2.1 `pilotstd/query/adapters/nrsis.py` —— HTTP 缺 `timeout`（可无限挂起）
`self._client.get(...)` 未传超时；外层有 3 次指数退避重试，但**没有超时意味着第一次就永久挂住**，
重试逻辑形同虚设。**修法**：`timeout=15`。
**回归**：`tests/unit/query/test_adapter_http_discipline.py::TestNrsisTimeout`（断言必带 timeout）。

### 2.2 `pilotstd/query/adapters/ahbz.py::_search` —— 每次查询泄漏一个连接池
每次 `_search` 新建 `requests.Session()` 并传给 `_search_single`，**从不关闭**。
**修法**：`with requests.Session() as session:`（响应体已在 `_search_single` 内读完，关闭安全）。
**回归**：`::TestAhbzSessionClosed`（断言 `__enter__`/`__exit__` 均被调用）。

### 2.3 `pilotstd/query/adapters/base.py::_try_exact_search` —— 可变默认参数
`accepted_statuses: set = {"exact"}` 是跨调用共享的可变对象（当前只读，未触发 bug）。
**修法**：默认改 `None`，函数内构造默认集合。
**回归**：`::TestNoMutableDefault`（签名为 `None` + 默认口径仍只接受 `exact`）。
