## 3. 前端定时器 17 处「set>clear」复核结论

- `CacheManager` / `ValidityConfig` / `WechatTrustIP` / `FileMonitor` 中的 `setTimeout` 全部是**一次性 UI 瞬时态**（如 `saved=false` 3 秒后复位），组件卸载后回调只写已卸载组件的 ref（Vue 3 无异常、非泄漏）；
- **唯一的周期定时器** `FileMonitor.vue` 的 `setInterval` 在 `onBeforeUnmount` 里 `clearInterval`（配对 ✓）；
- `test-env.ts` / `test-setup.ts` 的计数属测试基建（fake timers），不计入生产。
