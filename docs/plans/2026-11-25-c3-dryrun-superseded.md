## 2. 规则（与 `scripts/migrate_superseded_by_direction.py` 同一实现）

1. `superseded_by` 为空 → 跳过；
2. `year(sup) < year(std)`（方向倒退）→ 从本行去掉该值；
3. 目标旧标准行 `superseded_by` **只在该列为空时**才回填 `std`；已有值不覆盖；
4. `year(sup) >= year(std)` → 不动；多值逐条拆分。

即：按现行规则 `--apply`，这 15,755 条「被替代」关系会**永久消失**（本行清空 + 目标行不存在）。
这与台账 G-28 早期记录「直接写会覆盖 67% 目标值」的判断一致，本 dry-run 给出了精确口径。

**目标行已有值分布**（check_existing 口径，10,999 行命中）：
已空 10,122 / 正向已有值 **1** / 本身倒退 834 / 无法判年 42
→ 目标行几乎全是空或亦需清洗，**覆盖风险极低**；真正的问题在「目标行根本不存在」。
