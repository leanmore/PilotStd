# 福建站适配器价值评估（2026-11-26）：结论「无互补价值，放弃」

> 用户指令：对 `pt.fjbz.org.cn` 做快速数据摸底，判断 vs 现有站点（国标/地标/重庆/团标）是否互补；
> 若无互补立刻舍弃并在台账标记「已评估，无互补价值，放弃」。

## 1. 结论（一句话）

**放弃福建站**：其 DB35 元数据**已被 `dbba`（地方标准信息服务平台）完整覆盖**，全文也已由 `dbba` 提供
在线预览/下载；接入它需反爬破局（站点当前全端口 TCP 超时）而**没有任何新增能力**，投入产出比为 0。

## 2. 取证

### 2.1 元数据覆盖（实测，2026-11-26）

对 `dbba` 适配器（`dbba.sacinfo.org.cn`，官方「地方标准信息服务平台」，覆盖**全国**省/市 DB 标准）实测：

| 查询 | 结果 |
|---|---|
| `DB35/T`（关键词） | **15 条**（含 `DB35/T 2346-2026 德化白瓷 术语与分类` 等 2026 最新标准） |
| `DB35/T 1000`（精确号） | 1 条（`DB35/T 1000-2010`，状态「废止」） |
| `DB50/T 950`（对照，重庆） | 2 条（2026 新版 + 2019 旧版，状态区分正确） |

⇒ 福建地方标准（DB35）的**标准号、名称、状态**在现有 `dbba` 中已可查、可精确命中，无需福建站。

### 2.2 全文能力（二手取证）

`dbba` 官方平台已提供 **DB35 全文在线预览/下载**（搜索结果直接命中其 portal download 链接）：
`https://dbba.sacinfo.org.cn/portal/download/...`（如 DB35/T 2287—2025、DB35/T 1663—2017 的全文 PDF）。

福建平台（`pt.fjbz.org.cn:8060`）的差异化宣传点是「国标/行标/福建地标/台湾标准/国际标准全文阅览」，
但这些内容分别已被 `std_gov`（国标）、`dbba`（地标全文）、`api_webstore`/`asme` 等覆盖或超出本产品
「标准号查询 + 状态/替代关系」的核心需求。

### 2.3 接入成本（2026-11-24 侦查 + 2026-11-26 复测）

| 项 | 结果 |
|---|---|
| DNS | `pt.fjbz.org.cn` / `www.fjbz.org.cn` → `220.160.53.32` 正常 |
| TCP 80/443/8060 | **全部超时**（2026-11-24 与 2026-11-26 两次一致） |
| 接入需 | 代理池 / 逆向接口 / 长期维护反爬 —— 成本高且属「重复抓取」 |

## 3. 决策

| 项 | 内容 |
|---|---|
| 判定 | **已评估，无互补价值，放弃** |
| 影响 | 适配器节点 A3 关闭（不再等待网络放开）；路由链无需任何改动（`DB35` 本就由 `dbba` 兜底，已实测） |
| 保留 | 若未来出现「福建独家标准全文」的明确业务需求，可重新评估（触发条件写入台账） |
| 关联 | 适配器 A2 报告（`docs/plans/2026-11-25-adapters-phase1-a2-report.md`）中「福建 BLOCKED」段落更新为「已评估放弃」 |
