## 1. 规则 A（用户 2026-11-25 拍板）

对每行 `(std, superseded_by 多值拆条)`：

1. `year(sup) >= year(std)` 或无法判年 → **保留**；
2. `year(sup) < year(std)`（方向倒退）：
   - 目标旧标准行**存在**（`standard_number = sup` 有行）→ 从本行清除该值，并给目标行写反向指针（`target.superseded_by = std`）；
   - 目标旧标准行**不存在** → **保留原值**（清除会永久丢关系）；
3. 反向指针**只在目标行该列为空时写入**，已有值不覆盖；多来源逗号拼接。
