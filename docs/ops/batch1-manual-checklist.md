## 1. G-15 深色主题按钮对比度（3 类共 32 处）

**怎么做**：设置 → 外观 → 切到**深色**主题，浏览 15 个主要路由，重点看
`outlined danger` 按钮、悬浮工作台按钮、侧栏收起按钮。

**看什么**：按钮文字是否清晰可读（不需测量工具，人眼可辨即可；有 axe/Lighthouse 更好）。

**判据**：三处 CSS 修正后 dev 复扫 107 个按钮 0 个低于 AA。生产看起来应与 dev 一致。

## 2. G-17 Inbox 空目录自动清理

**怎么做**：在 `inbox/` 下建一个**只含 `Thumbs.db`** 的子目录，再建一个
「A/B/C 三层，只有最里层空」的嵌套目录，等 monitor 扫一轮（或触发一次扫描）。

**看什么**：
- 只含 `Thumbs.db` 的目录应被清掉（原缺陷：清不掉）
- 三层嵌套应**自底向上全部清空**（原缺陷：只清一层）
- 根目录本身不应被删

**判据**：`inbox/` 下不再残留这两个测试目录。

## 3. G-18 公告抓取起始日期默认值

**怎么做**：设置 → 公告抓取 → 看「起始日期」的**默认值**；再点一次抓取，观察请求参数。

**看什么**：
- 默认应是**最近 7 天**（不是"今天"）
- 应能**清空**为全量
- 三语提示应正确

**判据**：默认值 = 最近 7 天；可清空；清空后抓取从最早开始翻页。

## 4. G-19 `/api/clean-empty` 与 monitor 同口径

**怎么做**：用管理员 token 调 `POST /api/clean-empty`，或从设置页触发「清理空目录」。
构造与 #2 相同的三类目录（空 / 只含垃圾文件 / 非空）。

**看什么**：
- 空目录 → 清理
- 只含垃圾文件（`Thumbs.db`/`.DS_Store`）→ 清理
- 非空（有真实文件）→ **保留**

**判据**：与 monitor 的 `remove_dir_if_empty` 行为完全一致，无「垃圾文件目录漏清」。

## 5. G-20 四主题配色统一

**怎么做**：设置 → 外观 → 依次切 **light / dark / green / blue** 四个主题，
各浏览首页 + 一个列表页 + 一个弹窗。

**看什么**：
- 主按钮：底色与文字对比清晰（`--primary-fill` 与 `--primary-fill-hover`）
- hover 态**恒比常态更深**
- 文字梯度一致（标题/正文/次要/禁用）
- 描边可分辨

**判据**：四主题观感一致、无「同一元素在不同主题下语义色不一致」。

> 本地 `theme-spec.test.ts` 30 例已锁定数值；这一步只确认**渲染结果**与数值一致。

**怎么做**：给四个渠道（Telegram / 飞书 / 钉钉 / 企微）各配置一个**测试通道**，
