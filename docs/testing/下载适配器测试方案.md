## 可能遇到的问题

1. **网络不通**：说明当前 IP 不在中国大陆，需切换网络环境
2. **验证码**：ddddocr 可能识别失败，可传 `captcha_callback` 手工输入；每轮 2 次尝试、识别失败**不消耗** `_VIEW_ROUNDS` 轮次
3. **`verifyCode` 恒返回 `error`**：优先排查端点族——旧路径 `/bzgk/gb/*` 的 POST 会被 301 降级为 GET、body 丢失（**与 OCR 准确率无关**）
4. **`viewGb` 返回 200 + 0 字节**：会话授权未落地，适配器会自动重开下载页跑第 2 轮；两轮都空说明验证码未真正通过，或该标准暂无全文
5. **hcno 获取失败**：搜索页未收录该标准号（写法需一致），或站点搜索接口变更，需检查 `_HCNO_ROW_RE` / `parse_hcno_from_search_page` 的解析逻辑
