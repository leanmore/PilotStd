# 下载适配器测试方案

## 测试目标

验证 `c.gb688.cn`（国家标准全文公开系统）下载适配器是否正常工作。

## 前置条件

- **必须在中国大陆 IP 环境**下执行
- Python 环境已安装 `ddddocr`（可选，用于验证码自动识别）

## 执行方法

```bash
# 在项目根目录下执行
cd d:/PilotStd
python tests/manual_test_download.py

# 或在 tests 目录下执行
cd d:/PilotStd/tests
python manual_test_download.py
```

## 测试项

| # | 测试项 | 预期结果 | 实际结果 |
|---|---|---|---|
| 1 | c.gb688.cn 网络可达 | HTTP 200 或正常响应 | |
| 2 | csres.com 网络可达 | HTTP 200 | |
| 3 | njbz365.com 网络可达 | HTTP 200 | |

## 可能遇到的问题

1. **网络不通**：说明当前 IP 不在中国大陆，需切换网络环境
2. **验证码**：ddddocr 可能识别失败，需手动输入（脚本暂停等待）
3. **无下载权限**：部分标准仅支持在线预览，需启用精灵图拼接（sprite_assembler.py）
4. **hcno 获取失败**：标准平台搜索接口可能变更，需检查解析逻辑

## 反馈方式

将终端完整输出粘贴给开发者。
